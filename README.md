# schema-node-vue-view
Reusable Vue 3 components for visualizing schema-node data using Element Plus.

For the overall architecture, semantic model, and reference implementation, see [schema-node-csharp](https://github.com/kurapica/schema-node-csharp).

这是 SchemaNode 系统的 Vue 3 组件库实现。

关于整体架构、语义模型以及参考实现，请参阅 [schema-node-csharp](https://github.com/kurapica/schema-node-csharp)。
